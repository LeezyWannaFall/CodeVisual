## Ближайшая итерация

### CV-001 — Локальный роутер в Mount

Статус: DONE. Приоритет: P2. Тип: подтверждённый и исправленный дефект.

Сценарий: `sub := chi.NewRouter(); sub.Get("/users", H); r.Mount("/api", sub)`.
Проверить, что анализ выдаёт `/api/users`, а не только `/users`, и корректно
учитывает middleware. Сейчас обработка переменной в Mount ожидает builder.

Область: `internal/analyzer/httproutes/analyzer.go`.
Готово: минимальный пример воспроизведён; подтверждённая ошибка исправлена
и покрыта регрессионной проверкой либо гипотеза закрыта с объяснением.

Результат: регистрации сохраняются по экземплярам роутеров и разворачиваются
после разрешения Mount. Проверены два префикса, вложенные Mount, middleware
и диагностика циклического монтирования.

### CV-002 — Использование возвращённого роутера без Mount

Статус: DONE. Приоритет: P2. Тип: подтверждённый и исправленный дефект.

Сценарий: `r := Routes(); r.Get("/extra", H); return r`.
Проверить, что сохраняются внутренние маршруты Routes и добавленный `/extra`.
Предварительное исключение использованного builder из самостоятельного обхода
может приводить к потере его регистраций.

Область: `internal/analyzer/httproutes/analyzer.go`.
Готово: сценарий воспроизведён и результат зафиксирован; при подтверждении
добавлены исправление и регрессионная проверка.

Результат: builder анализируется при вызове с сохранением возвращённого
экземпляра. Проверены `:=`, `var`, добавление маршрутов, типизированные
обработчики и ссылки на middleware. Неопределённый результат builder диагностируется.

### CV-003 — Полный выбор маршрутов в Request Flow

Представление ограничено 200 узлами. Проверить проект с более чем 200 маршрутами
и обеспечить поиск/выбор остальных маршрутов.

Область: `web/src/App.tsx`, `web/src/components/RoutePicker.tsx`, API графа.
Готово: маршрут за пределами первой страницы доступен в выборе точки входа;
проверены поиск и обработка ошибок загрузки.

Результат: список точек входа загружает все страницы; проверены выбор 201-го
маршрута, ошибка следующей страницы и повторная загрузка. Добавлены проверки
смены snapshot и неполного ответа, исключающие бесконечную загрузку.

## Расширение: Python и Docker/Compose

Статус: DONE. Тип: новая возможность по запросу пользователя.

Одна команда определяет Go-only, Python-only и смешанный проект. Python и
конфигурация контейнеров не требуют go.mod. Workspace без корневого Go-модуля

### CV-011 — Схема Docker/Compose

Статус: DONE. Тип: новая возможность по запросу пользователя.

## Регрессионные исправления анализа

Статус: DONE, проверено локально.

- Builder Extend(r) получает исходные bindings, сохраняет идентичность роутера,
  middleware и обновляет алиасы переданного экземпляра.
